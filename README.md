# MotionNet

## Introduction
This dataset contains the trained models for our MotionNet code which can be found at (https://github.com/merlresearch/MotionNet)

## Dataset Organization

The size of the unzipped dataset is ~175MB and contains the following files:

* `model.pth`
* `model_MGDA.pth`
