## D-L1 mask 分支与 grid 损失配比失衡（2026-10-29，用户指令：定位并解决）

**现象**：`20261028_LEGO_STPN_s0` 训练 18 个 epoch，val fast 停在 4.3-4.5（零预测器基线 ~4.87），而 train disp 损失 ~0.03-0.06，与健康 run 同量级——位移头学不动。

**证据**（单 batch 梯度探针，`$EXP/_cache/cmdlogs/probe_loss_balance.log`）：

| 参数组 | grid 梯度范数 | mask 梯度范数 | 倍数 |
|---|---|---|---|
| stpn（共享骨干） | 1.21e-01 | 1.09e+01 | 90.8× |
| iaie（共享） | 4.6e-03 | 3.5e+00 | 764× |
| iebe（共享） | 1.10e-01 | 6.40e+00 | 58× |

- 加权损失占比：mask **98.4%**（4.46 vs 0.072）；共享骨干上两支梯度余弦相似度 **0.011**（近正交），后备表征被 mask 目标主导
- 论文正文（式 10）只写 "binary mask loss"，**5.0·BCE + 5.0·Dice 系数来自 notes 记忆、非论文原文**，配比存在合法调整空间（更早的假设"快速/静止格子权重稀释"被本证据取代：格子权重稀释解释 disp 损失小，但解释不了骨干梯度被 mask 淹没）

**选项**：
- A. 保留结构，缩放 mask 项（`loss.mask_scale`，本轮取 0.03 → stpn 上约 2.7×、iebe 约 1.7×、iaie 仍 mask 主导）
- B. mask 分支的骨干路径 detach（彻底隔离，但改变端到端语义）

**决定**：用户指令"快速定位并解决" → 先跑 A 的短程对照（3 epoch，`20261029_LEGO_bal03_s0`，val 每 epoch），基线 run 不动，作为对照保留。

**判定标准**：对照 run 的 e1-e3 val fast 若明显低于基线同期（e2 4.74 / e4 4.60，目标 <3.5 或呈清晰下降趋势）→ 失衡是主因，再决定最终 scale（0.01/0.03/0.1 小扫描）或改走选项 B。
