## 4. 与文献的偏差

slow 与 fast 在 1.0 s 地平线处均落入包络，管线可信。R1B 两种子的 fast@1.0s（1.023、1.070）与官方权重（1.011）几乎重合。R1A s1（bs8）的 fast@1.0s=1.146 高出包络上界 7%，与它的 val fast 同样偏高一致——bs8 配方即使不塌缩，收敛质量也略逊于 bs4。static 的均值口径 0.0145 低于包络下限 0.0201：静态格子误差帧间近似恒定，均值口径把 0.2 s 处的小误差一并平均，而文献口径未逐篇核对，可能只报特定地平线。【假设】若文献为 1.0 s 单点口径，我们同口径的 static 值为 metrics.json 的 per_frame_mean 最后一项。

## 5. 发现：一致性损失配方的零解风险（bs8）

bs8 + 一致性全开（上游 README 官方配方）在我们的栈上出现**种子依赖的零解塌缩**：

- 种子 0：位移头输出 45 epoch 内平滑衰减 0.10 → 0.002 m（train/eval 模式一致，骨干激活健康），val 指标冻结为 GT 统计（fast=4.87）。一致性损失在首个 epoch 内降至机器零——"全零位移"平凡满足 bg_tc/sc/fg_tc，而 disp 损失被 0.005 背景权重稀释（96% 静态格子），拉力不足。
- 仲裁：**上游原生训练器**同数据同 bs8 同栈复现衰减轨迹（epoch 5 |disp|=0.0228，与移植版 0.0189 相当）——非移植 bug（损失值 1e-6 对拍一致），align_corners 语义差异亦被排除（实测无差）。
- 种子 1：完整逃逸并健康收敛（fast 3.27→0.61，与 R1B 同档）——塌缩是早期轨迹分岔，非确定性行为。

对后续实验的操作含义：跑含一致性/先验类辅助损失的配方时，监控 epoch 1 的辅助损失值——若在数千样本内降到机器零且 disp 分项停在 0.02–0.08 不降，即塌缩信号，换种子或降辅助权重。此条直接适用于 P6 的 PriorMotion（VAE + KL 先验 + SGRU）复现。

## 6. 结论

- 我们观察到：官方权重在我们的评测协议下复现文献数字（1.0 s 地平线 slow/fast 入包络），管线可信。
- 我们观察到：R1B 项目预算（bs4）自训两种子达到官方权重同档水平，种子方差极小。
- 我们观察到：上游 bs8 配方存在种子依赖的零解塌缩风险，机制与判据已量化。
- 【假设】文献口径为特定地平线单点值；未逐篇核对。
