# reproduce_legomotion（P6 第二步：按论文实现）

状态：初稿（2026-10-30）。bal03 已完成 45 epoch；敏感性点 bal10（0.1）在跑、bal01（0.01）已发射。

## 1. 设置

- 代码已失，按 spec_legomotion.md（论文 IROS 2025 规格）从零实现：IaIE（式1-2）+ IeBE（式3-6）+ 三头 + 掩码头；**8.22M 参数 vs 论文 8.1M（+1.5%）**。
- 数据：motionnet_v1（零新增）；训练配方：45 epoch、bs2+累积2 等效论文 bs4、Adam 1.6e-3；两阶段 λ 调度照抄（前 20ep mask=2.0；后 25ep 网格项=2.0）。
- **Mask 配比（论文未给系数，来自用户 notes 的 5.0·BCE+5.0·Dice 在实现中需重配）**：盲用 1.0 时掩码损失占 98.4%、共享骨干上梯度为网格任务的 60-760 倍且近正交，网格头学不到（fast 停在零预测器水平）。降至 0.03 后恢复正常。配比选择用敏感性实验支撑（见 §4）。

## 3. 排查记录

1. **掩码梯度淹没（已解决）**：探针实测 mask 占总损失 98.4%、梯度近正交；`mask_scale` 重配后网格头恢复学习（bal03 的 disp 损失较基线降 5 倍）。配比选择待三点扫描（0.03/0.1/0.01）定论——0.1 在同期明显更差（e34 val fast 1.83 vs bal03 的 1.30），提示"越小越好"的方向，bal01 将验证边界。
2. **全局低于自家 MotionNet 基线（均值口径同样差 30%）**：差距不是长时域特有的（1.0s 与均值同比放大），且增益方向与论文相反（论文 −7.3%，本实现 +29%），OA 同步掉 5 个点——指向**实例增强分支（IaIE/IeBE）为净负贡献**，待两项 A/B 定位：
   - A：纯 bs4（论文配方；此前 bs2+累积2 的 BN 统计量与论文不一致，为与 RVpE 共卡的妥协）
   - B：实例分支旁路（g=to_grid(x)，网格头直接吃 STPN 原始特征；IaIE/IeBE/掩码头保留训练），直接判定增强分支的增益符号。判定窗口：e10 的 val fast（bal03 参照线 1.685）。
3. **尚未验证的论文细节**：IaIE 的 query 层数与 DETR 初始化的具体形式、IeBE 晚期融合 FFN 维度、"any training strategies are not used in our reported results" 是否意味着论文表格数字未用两阶段调度——这些均为 spec 歧义（已记录在案），可能贡献剩余差距。

**发现**

1. **fast 在 e40 饱和**：1.300@1s（均值 0.7706），e45 与 e40 完全等价（1.3041 / 0.7713，−0.1%）。45 epoch 预算本身不是瓶颈。
2. **slow 持续改善到 e45**（0.4212→0.3108@1s，−26%），OA/MCA 同步上升（0.771→0.905）——后期收益来自 slow 与分类，而非 fast。
3. **static 全程平/噪声**（@1s 0.033-0.042，最低反而在 e10），无后期收益。
4. **与 RVpE s1 的逐 ckpt sweep（`P6/ckpt_sweep/s1_ep20-45`）对照**：s1 的 fast 在 e25 即饱和（0.9036@1s），其后 static 单调改善 19%、fast 仅 0.6%；LEGO 相反，fast 到 e40 才饱和，static 不动、slow 继续降。两者"后期收益来源"不同，说明分桶饱和点由监督结构决定，不能跨模型套用。
5. **选点建议**：单 ckpt 报 e45（fast 与 e40 等价、slow 最好、分类最好）；若按均衡/Pareto 选，e35-40 与 e45 的 fast 差 <8.5%，无实质差异。
